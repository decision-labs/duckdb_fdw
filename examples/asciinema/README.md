# Live DuckLake-over-Quack demo

Asciinema of Postgres querying and inserting through `duckdb_fdw` into the local Geobase **demo** lake (`lake` server → `remote_lake.fdw_demo` / `airports`). No credentials are typed.

Play locally:

```bash
asciinema play examples/asciinema/ducklake-quack-live.cast
```

Online player (anonymous upload, may expire): https://asciinema.org/a/3CMqlXt6oIx4us6I
